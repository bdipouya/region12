# ربات شهرداری منطقه ۱۲ تهران

نسخه ۱ شامل:
- منوی اصلی و زیرمنوهای گردشگری، ملاقات مردمی، اخبار، خدمات شهری، ثبت درخواست، شهروند خبرنگار، رویدادها، اماکن و تماس با ما
- ثبت درخواست شهروندی با کد پیگیری
- دریافت گزارش شهروند خبرنگار و ارسال آن برای ادمین
- ثبت درخواست ملاقات مردمی
- پنل ساده ادمین برای مشاهده درخواست‌ها و افزودن خبر/رویداد/جاذبه گردشگری
- SQLite برای شروع

## راه‌اندازی در ویندوز

1. Python 3.10 یا جدیدتر نصب باشد.
2. این پوشه را باز کنید.
3. ترمینال را در همین پوشه باز کنید.
4. اجرا کنید:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

5. فایل `.env.example` را به `.env` تغییر نام دهید.
6. مقدار `BOT_TOKEN` را با توکن BotFather پر کنید.
7. مقدار `ADMIN_IDS` را با آیدی عددی تلگرام ادمین‌ها پر کنید. چند ادمین را با کاما جدا کنید:
```text
ADMIN_IDS=123456789,987654321
```
8. اجرا:
```bash
python bot.py
```

تا وقتی پنجره ترمینال باز است، ربات فعال است. برای اجرای ۲۴ ساعته بعداً آن را روی سرور/VPS مستقر می‌کنیم.

نکته امنیتی: توکن BotFather را داخل چت یا Git منتشر نکنید.
